# 🧩App のミニアプリの実装計画(タイマー・ToDo・2048・マインスイーパー・天気・ニュース)

App のメニューに、アプリ・画面・モデルの実装の見本になる小さなアプリ(タイマー・ToDo・2048・マインスイーパー)を足す。あわせて、ダミーのデータで UI に天気とニュースの画面を足す(基本の画面を作ってから、1 つずつ強化する)。番号は `Task_Checklist.md` の 7 と同じ。

| 番号 | 段階 | 内容 |
| --- | --- | --- |
| 7-1 | タイマー | ストップウォッチとカウントダウン。背面やアプリの終了をまたいでも合う時間、終了の通知 |
| 7-2 | ToDo | 一覧と、Push / Pop で開くダイアログ的な編集。SQLite(既存の `data.db`)への保存 |
| 7-3 | 2048 | スワイプでの操作、モデルの結果から作るタイルのアニメーション、途中の盤面の保存 |
| 7-4 | マインスイーパー | 描画で作る盤面とタップ位置からのセルの特定、長押しで旗、最初の 1 手を安全にする配置 |
| 7-5 | 天気(UI) | ダミーのデータで UI に天気の画面を足す。7-5-1 で基本の画面を作り、7-5-5〜7-5-8 で強化する |
| 7-6 | ニュース(UI) | ダミーのニュースで UI に、上部のタブと左右のスワイプで切り替える画面を足す。7-6-1 で基本の画面を作り、7-6-2〜7-6-8 で強化する |

ファイルパスは `Template.MobileApp/` からの相対。

## ⚖️決定事項

| 項目 | 決定 |
| --- | --- |
| 置き場所 | 画面は `Modules/App/`(`AppXxx`)、モデルは `Models/App/` にアプリごとに 1 つのファイル(ゲームは `XxxGame.cs`、道具は `XxxApplication.cs`。MAUI に依存しない)。型の名前はアプリの名前で始める(2048 は `Puzzle2048`)。盤面のコントロールは `Controls/XxxBoard`。VM はモデルの状態を画面に写し、操作をモデルに渡す |
| 画面の数 | 1 画面。ToDo だけ一覧と編集の 2 画面にする(編集の開き方は 7-2) |
| 表示 | VM は状態(列挙・数値・時間)を持ち、文言・色・表示の切り替えは XAML のコンバーターとトリガーで行う |
| 時刻 | `TimeProvider` を DI に登録し(`TimeProvider.System`)、VM が現在時刻をモデルに渡す |
| 乱数 | `RandomNumberGenerator.GetInt32`(CA5394 の抑制が要らない)。モデルは乱数を `Func<int, int>`(0 以上 n 未満)で受け取り、決まった値を渡して確かめられる形にする |
| 保存 | ミニアプリの状態(続きの盤面・ベストの記録)は `Settings` に持たず、アプリごとの JSON のファイルにする(`Services/JsonStore`。アプリのデータフォルダーの `json/` に型の名前で置く。型は `Models/App/AppJsonContext.cs` のソース生成)。ToDo は SQLite(既存の `data.db`) |
| メニュー | App のメニューは、道具(Calculator / Timer / ToDo)を 1〜3 行目、1 行空けてゲーム(Sudoku / 2048 / Minesweeper)を 5〜7 行目(`Grid.Row` 4〜6)に並べる。アイコンは `AppIcons` に Timer / Checklist / Grid4X4 / Flag を足す |
| UI のメニュー | 天気とニュースは UI 1 の Timeline の前の行(`Grid.Row="6"`)。Graph / Graph2 / TreeMap は UI 2 に移す(Graph / Graph2 は Load の前の行、TreeMap は Meter の次の行で Radar と並べ、その次の行を Wheel / Monster にする)。Stream / Dock は UI 1 の最後の行に移し、UI 2 は上に詰める(最後の行が空き) |
| ファンクションキー | F1 = Back は共通。F2〜F4 は各節。タイマーと ToDo は使わない(戻るも含めて画面の中のボタンで操作し、ヘッダーとファンクションキーの帯を隠す) |

## ⚠️制約

- タイマー: 正確なアラームの許可(`SCHEDULE_EXACT_ALARM`。Android 14 以降は既定で不許可)が無いので、背面で終わったときの通知は遅れることがある(Pixel 9a で約 50 秒)。時間は端末の時計(UTC)から計算するので、計測中に端末の時刻を変えるとずれる
- ToDo: `data.db` は起動のたびに作り直すので、ToDo の行もアプリの起動で見本の行に戻る。`IDialog.Snackbar` はボタンを持てないので、元に戻すは画面の中の帯で出す
- 2048: 縦の `ScrollView` の中ではスワイプがスクロールと競合するので、盤面は `ScrollView` の外に置く
- マインスイーパー: 中級(16×16)はセルが小さい(幅 360dp の画面で約 20dp)
- ニュース: Debug ビルドでは、画面を開いた直後の最初の速いスワイプ(0.2 秒)が、ページを変えずに戻ることがある(ページの途中では止まらない)
